## Historias de Usuario

### Rol: Cliente
- **HU-01:** Como cliente, quiero ver el menu del día con precios y disponibilidad para seleccionar mis platos.
- **HU-02:** Como cliente, quiero armar un carrito de compras interactivo para modificar cantidades o eliminar items.
- **HU-03:** Como cliente, quiero enviar mi ubicación GPS nativa para indicar donde recibir el pedido.
- **HU-04:** Como cliente, quiero recibir un QR de pago y adjuntar mi comprobante para confirmar el pedido.
- **HU-05:** Como cliente, quiero recibir notificaciones automáticas del cambio de estado de mi pedido.

### Rol: Delivery / Repartidor
- **HU-06:** Como repartidor, quiero recibir notificaciones con los detalles y ubicación del pedido asignado[cite: 1].
- **HU-07:** Como repartidor, quiero compartir mi ubicación en tiempo real para que el cliente y el administrador vean mi trayecto[cite: 1].
- **HU-08:** Como repartidor, quiero registrar la llegada y entrega efectiva del pedido con evidencia[cite: 1].

### Rol: Administrador
- **HU-09:** Como administrador, quiero gestionar los platos (CRUD), su stock y la programación por fecha[cite: 1].
- **HU-10:** Como administrador, quiero verificar comprobantes de pago y descontar stock automáticamente[cite: 1].
- **HU-11:** Como administrador, quiero asignar o reasignar repartidores a pedidos especificos[cite: 1].
- **HU-12:** Como administrador, quiero visualizar reportes de ventas, platos mas pedidos y tiempos de entrega[cite: 1].
